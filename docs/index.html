From AgentstoEcosystems

A step-by-step tutorial for building agentic systems from first principles.

Start with a synthetic financial world. Give one agent tools and skills. Organize agents into constellations. Add feedback. Let the system redesign its own organization. Then let constellations discover, negotiate, collaborate, and adapt as an ecosystem.

The central idea

Do not begin
with a black box.

This tutorial is deliberately cumulative. Each notebook introduces one new level of coordination, autonomy, and adaptability while preserving the mechanisms built before it.

The goal is not merely to use a powerful model. It is to understand how system intelligence emerges from tools, skills, roles, permissions, state, evaluation, reconfiguration, contracts, provenance, and institutional coordination.

The discipline that survives

More autonomy.
More explicit
governance.

In finance, an answer is not enough. The system must make it possible to reconstruct what evidence, permissions, state, evaluation, revision, and organizational structure produced that answer.
Bounded toolsDeterministic operations remain explicit and testable.
Role permissionsSpecialists receive only the tools and evidence appropriate to their responsibility.
Independent evaluationDecision agents do not secretly define their own success criteria.
Provenance and lifecycleVersioning, contracts, messages, shared knowledge, and cleanup remain inspectable.
